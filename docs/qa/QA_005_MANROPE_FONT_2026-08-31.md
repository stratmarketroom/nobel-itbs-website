# QA-005 Manrope Font — 2026-08-31

Status: implemented, merged, deployed, and accepted

## Summary

The approved Manrope brand typeface is now loaded through `next/font/google`
as a variable font. Next.js downloads the WOFF2 files at build time and
self-hosts them from the Nobel ITBS deployment, so public browsers do not
contact Google Fonts.

The generated `--font-manrope` variable is mounted on the root `<html>` element
and used as the first family in the global font stack. `display: swap` and the
Next.js metric-adjusted fallback reduce invisible-text and layout-shift risk.

Only the shared Latin subset is preloaded on every route. The same generated
CSS self-hosts Cyrillic and Latin Extended unicode ranges, which browsers fetch
on the Ukrainian and Czech routes that actually need them. This avoids loading
all three language subsets on every English page.

## Baseline

The 2026-08-31 Production Lighthouse audit found no font request in 30 runs
because Manrope was declared only by name and `--font-manrope` was undefined.
The browser therefore rendered a platform fallback. Median mobile LCP was
1.99–2.14 seconds and CLS was 0 across the five-route matrix.

### Focused Lighthouse Check

Lighthouse CLI 13.4.1 was run three times against the local production build's
mobile `/verify` route using the same default simulated mobile throttling as
the baseline audit.

| Variant | Performance median | LCP median | CLS median | Font transfer |
| --- | ---: | ---: | ---: | ---: |
| All three subsets preloaded | 96 | 2.82 s | 0 | 57.7 KiB |
| Final Latin-only preload | 97 | 2.64 s | 0 | 25 KiB |

The preload correction removed two unnecessary English font requests, improved
the median score, and preserved zero layout shift. The local result is not an
apples-to-apples comparison with the previously measured Vercel Production
median (97 score, 2.14-second LCP), so it is retained as local optimization
evidence rather than presented as a direct Production comparison. The merged
Production response now preloads a same-origin WOFF2 asset and retains zero
external Google Fonts access in its CSP.

  this is not a blocker for the accepted Manrope loading implementation.
